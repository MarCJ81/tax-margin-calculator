# 1인사업자 부가세·종소세·순수익 계산기

1인 사업자·프리랜서·자영업자가 매달·분기마다 가장 헷갈리는 **부가가치세, 5월 종합소득세 정산, 세금을 빼고 실제 손에 쥐는 돈**을 10초 만에 가늠하는 무서버 정적 웹앱입니다.
`index.html` 하나로 동작하며, 계산은 100% 브라우저에서 이뤄집니다. **서버 전송 0건, CDN·분석 도구 0개.**

- **① 간이과세 vs 일반과세 부가세 비교** — 연 매출·매입을 넣으면 두 유형의 납부세액과 유불리를 나란히 계산
- **② 3.3% 프리랜서 종합소득세** — 단순경비율·실제 경비로 5월 환급액 또는 추가 납부액 계산
- **③ 월별 순수익 시뮬레이터** — 고정비·플랫폼 수수료·카드매출을 반영한 순이익률과 "세금 통장" 적립액
- 요약 리포트 복사 / JSON 백업·복원 / A4 1쪽 인쇄·PDF
- 입력값은 `localStorage`에 자동 저장(이 기기에만), 언제든 초기화 가능

## 바로 쓰기

1. `index.html`을 브라우저에서 연다(로컬 파일 또는 정적 호스팅).
2. 위쪽 **①부가세 비교 / ②3.3% 종소세 / ③월 순수익** 탭에서 필요한 계산을 고른다.
3. 처음 열면 예시 값이 채워져 있다. 우리 매출·매입·고정비로 바꾸면 결과가 즉시 갱신된다.
4. `A4 인쇄 · PDF` → 인쇄 창에서 용지 **A4**, 배율 **100%**, 대상 **PDF로 저장**.

> 입력값은 그 브라우저의 `localStorage`에만 남습니다. 어떤 값도 외부로 전송되지 않습니다.

## 계산 방식과 한계

- **부가세**: 모든 금액은 부가세 포함(공급대가) 기준입니다. 일반과세는 매출세액에서 매입세액을 빼고, 간이과세는 업종별 부가가치율을 곱한 뒤 매입 0.5%·카드 발행세액공제를 뺍니다. 두 공제 모두 납부세액을 넘지 않습니다(간이과세는 환급 없음).
- **종소세**: `총수입 − 필요경비 = 사업소득금액` → 기본공제·국민연금·노란우산·기타 소득공제 → 과세표준 → 누진세율 → 표준세액공제·기타 세액공제 → 소득세 + 지방소득세. 기납부 3.3%와 비교해 환급/추가납부를 표시합니다.
- **단순경비율 요건**: 직전 연도 수입금액이 업종군 기준(서비스업 2,400만원, 제조·숙박·음식점 3,600만원, 도소매 6,000만원)에 미달할 때만 적용됩니다. 넘으면 기준경비율 또는 장부 신고 대상이라 이 앱의 결과와 달라집니다.
- **건강보험료**: 사업소득의 필요경비로 인정되므로, 장부 신고에서는 실제 경비에 포함해 입력하는 것이 가깝습니다(단순경비율 신고 시에는 경비율에 포함된 것으로 봄).
- **월 순수익**: 월 금액을 12배 해 연간 부가세·종소세를 계산한 뒤 12로 나눈 **적립 참고액**입니다. 실제 납부는 1월·7월(부가세)과 5월(종소세)에 몰립니다. 소득은 부가세를 제외한 공급가액 기준입니다.
- **세액공제·감면**: 자녀세액공제, 연금계좌, 보험료·의료비·교육비, 중소기업 특별세액감면 등은 넣지 않았습니다(기타 세액공제 칸에 직접 합산 가능). 실제 신고는 **홈택스 신고서 또는 세무사 확인**이 필요합니다.
